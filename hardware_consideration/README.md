# Hardware Consideration & Sim-to-Real Framework

本ディレクトリは、強化学習（SAC / PPO）を用いたロボット制御において、**「シミュレータと実機のギャップ（Sim-to-Real Gap）」を埋めるためのハードウェア制約モデルおよび制御インターフェイスの検討モジュール**です。

## Key Features (実機化に向けた設計思想)
1. **トルクの一次遅れフィルタ (Low-Pass Filtering)**
   - モータ指令値の急激な変化によるドライバや減速機への負担を防ぐため、物理的な応答遅れを模倣した平滑化処理を実装。
2. **起動時のソフトスタート (Torque Ramping)**
   - 制御開始直後（初期ステップ）の急激なトルク跳ね上がりを抑制し、実機の安全な立ち上がりを担保。
3. **モータドライバの不感帯 (Deadband) の模倣**
   - 微小トルク域におけるギヤフリクションやコギングの影響をモデル化し、ロバスト性の高い制御方策の獲得を促進。
4. **ドメインランダマイゼーション (Domain Randomization)**
   - 質量、摩擦係数、減衰係数にランダムな揺らぎを与え、実機の個体差や環境変動に対する耐性を向上。
